## 🚀 How to Run the Programs

1. Clone this repository:bash
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open Eclipse IDE.
3. Import the project using **File → Import → Existing Projects into Workspace**.
4. Navigate to the required package.
5. Open the Java class containing the `main()` method.
6. Right-click and select **Run As → Java Application**.
